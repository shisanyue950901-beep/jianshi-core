# 见势｜找项目页面第一轮减法与分类卡片验收（2026-10-13）

**决定来源**：B0 商业冻结「个人创业机会发现为主、企业 AI 服务为第二业务线」；10 月 13 日用户指明公开 UI 一眼可懂；参考此前原创见势 2.0 视觉母版和 Super-i 内容频道的分类/卡片/详情结构。本批实装而非再规划一套新网站。

## 为什么改

旧 `/discover/` 是 17 条混合资料：4 条企业 AI 方案、6 种商业模式、3 个有经营披露的历史公司案例、4 条网站指南。**企业方案排在项目之前**，首次进入即展示「G2 / PUBLIC DISCOVERY」「CONTENT DIRECTORY」与资料清单说明。用户从首页点击「按方向找项目」，没有第一眼看到想研究的创业生意。

## 交付内容

- 首页已有主按钮 `/discover/` **不变**；将该页默认筛选从「全部 17 条」改为「找创业方向：9 条」，即 **3 个具名公司历史案例 + 6 类匿名商业模式**。9 条是内容合计，不是 9 个真实可直接启动的新项目或已经证明利润的商机。
- 允许按「真实公司案例」「生意模式」「企业用 AI」「其他」「全部内容」切换，现有 17 条固定公开路由均完整保留。仅改变呈现顺序：**真实案例→商业模式→企业 AI→其他**。
- 具名案例卡直接显示「谁付钱、怎么收费／怎么赚钱」，例如 NerdWallet 的读者不是广告付款方；模式卡显示一般性的收费方式。不得用这些文字推断其他公司的财务或个人收入。
- 页面标题「找创业项目，先看怎么赚钱」，删除正面技术阶段标签和冗长的构建说明；保留一句风险「历史案例不代表自己做也能赚钱」，原始来源在案例详情里仍可查。
- 在搜索框输入文字时自动切换为「全部内容」范围（避免输入「自动化」却因默认创业分类而找不到企业 AI）；点击「清除筛选」恢复 9 条创业相关内容。无外部请求/跟踪、无账号和输入持久化。
- UI 复用现有 `f21_design_tokens`、站点头尾栏和卡片 CSS；并未使用或复制 Super-i 的第三方图片、文字、代码。
- 核验接口：`f21_g2_discovery.render()`；原 17 条路由的构建时存在性审计保持不变；新增 9/17 项目的默认状态、分类、搜索、空结果、重置 JS 行为测试。

## 安全/商业边界

- 生产数据库、Supabase、Cloudflare Worker、Auth/CMS/支付/撮合均不修改。
- P4.41 两条采集 Cron、配额、API 和私有研究审核链原封不动。
- **不新增未核实项目、预算、客户、真实利润、课程或已交易业务。**
- 原 `/research/` 六份详细匿名研究此批保持不变；涉及页面深度的下一轮改造应只改源模块，独立 PR 且保留来源及匿名限制。
- 静态 HTML/JS 自动测试和云端文本验收不能替代真实 390/1440px 截图、点击、手机及 5 名创业者观察。

## 交付验收

| 检查 | 预期 | 真实状态 |
|---|---|---|
| 源码 | 17 条原 URL 均保留，默认只显 9 条创业研究资料 | 提交后由 CI 判定 |
| 交互 | 分类切换、全站关键词搜索、空结果及重置 | 提交后由 JS 测试判定 |
| 一眼看懂 | 先展示「做什么、谁付钱、怎么收费」；企业方案被独立分类 | 需要真人观察 |
| 历史/许可 | 严格来源门禁和实际付款方正确，已验证直接盈利项目不增加 | CI + 后续审计 |
| 上线 | main CI、静态快照、私有采集 SKIPPED；CDN 实际 HTTP 内容 | 分项记录，不能用 CI 冒充线上 |

**最终用户价值**：来见势找项目，不需要先看「资料中心」和我们的工程体系。首页→按方向找项目→公司/模式卡→项目详情，形成一条清晰链路。
