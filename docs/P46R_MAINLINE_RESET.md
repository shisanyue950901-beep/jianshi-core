# P4.6R 主线纠偏：回到见势最初产品目标

日期：2026-10-07  
状态：MAINLINE_RESET

## 唯一核心目标

见势当前只做一件事：

> **获取海外已经被真实市场验证过的一人公司 / 小团队项目，进行筛选、中文解释和推荐，帮助中国用户找到值得继续研究的创业项目。**

不再把产品扩展成复杂的“全渠道创业顾问”。

## 用户是谁

当前核心用户：

> **寻找创业项目、创业方向和可复制商业模式的中国中文用户。**

不是默认面向：
- 内容创作者；
- 自媒体运营者；
- 海外营销从业者；
- 投资交易用户。

这些人未来可能使用见势，但不是当前产品结构的第一出发点。

## 信息流程

冻结为：

```
海外真实项目
    ↓
是否有商业验证
    ↓
是否适合个人 / 小团队
    ↓
哪些部分具有可复制性
    ↓
翻译成中文
    ↓
给中国用户推荐
```

## 一个详情页只回答 6 个问题

1. 这个项目是什么？
2. 海外有没有真实验证？
3. 为什么值得中国用户看？
4. 适合什么样的中国个人创业者？
5. 第一步怎么低成本验证？
6. 最大风险和当前未知是什么？

## 删除的默认复杂度

从通用详情模板中移除：

- 国内 / 海外渠道矩阵；
- 抖音 / YouTube / TikTok 等强制平台罗列；
- 内容创作者路线；
- 为了“完整”而强制填写获客平台；
- 把每个项目拆成国内版 / 出海版两套路线。

平台只有在以下两种情况下出现：

1. 平台本身就是这个项目的一部分，例如 Amazon FBA、YouTube 媒体；
2. 有直接证据表明该平台是这个项目的关键销售或分发机制。

否则不写。

## 数据的角色

冻结：

```
DATA_SERVES_PRODUCT = TRUE
PRODUCT_IS_NOT_DEFINED_BY_AVAILABLE_DATA = TRUE
```

有 PyPI、GitHub、Empire 或任何新数据源，不代表网站必须增加对应栏目。

数据只用来回答：

> “这个海外项目是否真实存在、是否被市场验证、是否值得推荐给中国用户继续研究？”

## 推荐状态

当前只保留三档：

- 优先研究
- 值得研究
- 继续观察

暂不使用“稳赚”“必做”“高收益”等结论。

## P4.6A 两个样板的修正

保留：
- 垂直行业 SaaS
- Amazon FBA 细分品牌

但页面统一改成：
- 见势推荐
- 项目是什么
- 海外真实验证
- 对中国用户的参考价值
- 第一轮验证
- 风险与未知

不再默认显示渠道矩阵。

## 下一步

在这次主线纠偏通过 CI 后，再继续扩展项目数量。

下一批优先仍应是“海外已有真实商业验证、且中国用户容易理解”的项目，而不是按内容平台或技术数据源分类。
