# 见势 P4.19｜留白与视觉节奏改造验收（2026-10-09）

## 本轮目标
在 P4.18 信息层级基础上，不新增文字事实、不改变卡片的收费语义、不改动图片、开屏或 3D 动画，改善从首页至研究库的阅读节奏。

## 可见变化
- **页面内容宽度**：普通章节最大 1380px，左右自动居中；避免大屏正文与卡片横跨整块屏幕。
- **章节呼吸感**：普通章节顶部使用 `clamp(88px, 9vw, 148px)`，小屏使用 `clamp(70px, 10vw, 94px)`。章节标签上边距略增、下段与正文更有区分。
- **封面视觉墙**：在较宽屏幕由 3 列改为 4 列（阈值 1100px），八张现有封面排列更整齐，占屏高度下降；窄屏保留现有单列／双列规则。
- **搜索／筛选**：搜索框、内容类型、三个商业维度及状态数量统一组成一块略带底色的面板，并随浅色／深色使用不同 `--panel` 变量。
- **真实项目研究库**：研究库顶部留白增加，卡片改为有间隔、有边框的独立信息面板，桌面宽屏由 2 列改为 3 列，手机仍单列。
- **商业模式列表**：6 张模式卡从相邻的细线网格变成带呼吸间距的独立卡片。
- **详情页**：两列条目间距由固定 24px 调整为响应式 28–50px，使重点内容不挤压。

## 冻结约束
- 继续使用默认浅色、手动深色切换及原有偏好持久化。
- 8 张原内嵌 WebP、3D 转动、灯箱、开屏、减少动画、焦点与路由合同均不改。
- 20 个具名项目、6 个商业模式、财务未核实口径保持原状。
- GitHub CI 执行；生产输出 `web/dist`，单 HTML 文件、单 CSS、单 JS、UTF-8 严格小于 250000 字节。
- PR #52、Supabase Production、Cloudflare Workers、Pages 构建配置均不触碰。
- **不使用 TinyFish 付费浏览器**，本次以自动化测试、Cloudflare 预览构建与公开静态站点取证为发布门禁。没有进行的人工真机 Safari 截屏验收应明确标为 PENDING，而不能虚报。

## QA 建议
人工目视优先检查：电脑 1440/1920px 大屏节奏、390px 与 320px 小屏搜索面板、长标题项目卡片、浅／深色对比、切换类别与收费说明高度。所有视觉位置、自动布局和 UI 质感都可能在真实设备上需微调。
