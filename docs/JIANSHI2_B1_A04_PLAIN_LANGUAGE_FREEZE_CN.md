# 见势 B1-A04｜看项目，不看术语：页面简化冻结（2026-10-13）

## 产品判断

用户进站的第一任务：**找项目并判断是否值得自己进一步研究**。之前首页把概念主视觉、平台指标、三条研究路线、五大业务框架放在项目之前，信息层级反了。面向普通人不应展示任何工程阶段名、内部模型编号或繁琐审核流程；那些保留在后台与详细来源中。

**第一屏三问**：做什么、怎么赚钱、难不难做。**列表必须在导航和数据概况之前出现。**

## 本轮交付

1. 首页缩短首屏：`想找个项目做？` 与 `直接看项目`，紧接三个已有的真实历史案例（Carrd/Plausible/NerdWallet）。保留 1 张旧概念图但缩小；移动端不占屏幕空间。
2. 案例卡先回答：**谁需要、怎么赚钱、上手门槛**。摘要取自已经审核的项目资料与已有创业适配编辑研究。不能把集团广告收入说成普通用户付费，也不能把成熟平台案例说成低成本可复制项目。
3. 项目列表调整为「看看它们怎么赚钱」，优先展示做什么、谁可能付钱、收费方式；长篇证据排名说明折叠在「这些项目怎么选出来的？」中。浏览来源、报告与未知风险仍能在项目详情获取。
4. 搜索、五个旧导航模块与锚点、三条研究路径、静态项目详情、证据原始链接继续有效；四个企业方案仍作为第二业务线，明确「尚未开放真实采购」。
5. 内部 CI、安全门禁、真实业务证据准入和每日扫描预算保持原样。官方项目数仍然只有 3 个历史经营证据案例，**0 个已证明可以直接启动**。不为填充 UI 制造虚假热门项目。
6. 仅调整源模块和测试；不编辑 `web/dist` 生成物、不启用 Supabase Auth/CMS、Cloudflare Worker、企业撮合、支付、跟踪、用户登记。

## 验收

| 条目 | 自动验证 | 真实用户验证 |
|---|---|---|
| 首页先看到项目 | HTML 结构中项目列表位于指标、五入口和企业方案之前 | 手机及 PC 截图/操作进一步复核 |
| 每卡秒懂商业模式 | 三卡每张有「谁需要」「怎么赚钱」「上手门槛」，禁止不经核实的收入承诺 | 真实创业者能用自己的话解释 |
| 项目列表不逼用户读报告 | 上方通俗介绍，复杂收录规则折叠 | 用户无需读规则即可进入项目 |
| 遗留内容与安全 | 全量 CI、静态构建、四步私有采集 SKIPPED | Cloudflare 在线内容只读核验 |
| 商业验证 | 不可自动证明 | 真人访谈、回访、付款仍是 NOT_TESTED |

### 下一阶段
