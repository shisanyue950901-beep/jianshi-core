## 1. 用户目标

用户要的是“找到并看懂一门海外正在有人经营的生意”，不是审查评分引擎、数据流水线或采集来源。

每个商业模式详情页统一回答：

1. 这是什么生意，卖什么？
2. 谁会购买？
3. 收入从哪里来？
4. 日常怎样经营？
5. 通常有哪些成本？
6. 海外可参考的信息属于什么性质？
7. 还要确认哪些未知？
8. 如果继续研究，应该先问哪三个问题？

**交付内容：** `config/p412b_business_content.json` 内含六类完整中文编辑稿。
`web/prototypes/p412a/index.html` 中六个详情页均已用这些稿件替换简略占位介绍；双主题设计保留。

## 2. 公开页面边界

- 六类是商业模式分类，**不是六个特定企业**；
- 模式知识可以解释一般运作机制，但不能冒充某个匿名案例的实际经营细节；
- “产品形态示例”只能表示一种常见产品形态，不表示已核实公司或销量；
- **没有可核实的具体公司资料，就不写虚构公司故事**；
- 成本部分只列真实可能涉及的类别，不杜撰具体费用、利润率或启动预算；
- 不公开内部采集供应商、数据源网址、原始项目标题、编号、后台版本、处理流程；
- 海外经营记录能支持“存在这一类生意”，但不能直接证明其在中国适配、个人可运营、获客稳定或回报可复制；
- 真实经营数字应由后续安全、白名单化且获批准的汇总模块接入，而不是写入通用文章。

## 3. 六类内容主体

| 类型 | 用户首先理解什么 | 需要警惕的误解 |
|---|---|---|
| 行业软件订阅 | 软件解决什么重复问题；谁愿意持续付费 | 订阅不等于自动稳定收入 |
| 数字产品 | 买到什么文件/使用权；怎样交付 | 没有库存不等于没有获客、更新成本 |
| 内容与联盟营销 | 内容如何帮助决策；广告与佣金如何形成 | 流量不等于成交 |
| 亚马逊数字出版 | 作品、读者、平台、出版者各是什么角色 | 按需印刷不意味着出版者无需承担制作和获客 |
| 跨境电商品牌 | 商品销售及库存履约逻辑 | 营业额不等于实际利润 |
| 专业服务 | 客户需要的结果与服务交付内容 | 有订单不意味着可不增加人力而规模化 |

## 4. 两个重点样板

### 数字产品

页面必须自然解释：
- 什么叫可数字化交付的商品；
- 下载交付与在线授权两种常见方式；
- 哪些人会为模板、素材、工具付费；
- 单次购买、授权与订阅不相同；
- 主要经营工作除了制作，还包括获客、支持、版本更新；
- 不把产品形态举例写成“海外已核实企业案例”。

### 亚马逊数字出版

页面必须自然解释：
- 电子书、纸质书都是可能的出版形式；
- 出版者负责选题、内容、版权、封面、上架信息与推广；
- 部分纸质书可采用按需印刷；
- 销售结算、版税以及印刷成本依据版本、格式、地区和规则而不同；
- 不写固定“每本书必赚多少”的示意数字；
- 不假装掌握某个匿名出版者的真实图书销量与运营团队。

## 6. 版面层级

首页：业务名称 → 一句话“做什么” → 主要收入方式 → 打开详情。  
详情：业务说明 → 买家 → 收费 → 日常经营 → 成本 → 海外参考 → 核实问题。

过去项目页面在视觉上重复强调“第三方数据如何处理”，新版只在信息必要时说明一次，不向用户讲后台技术与安全工程。

保留 P4.12A 深色/浅色切换，不重新设计主题。
