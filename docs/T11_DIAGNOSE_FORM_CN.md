# T11｜见势项目诊断飞书表单搭建说明

## 用途与隐私边界
仅使用飞书外部表单。见势网站只显示表单入口，不提供站内表单、不保存项目说明、联系方式或身份信息。诊断信息由飞书表单系统接收；建表前请设置访问权限、使用目的、删除/保留期限和处理人。联系方式仅用于回复诊断，不能用于未经同意的群发营销。

建表完成后，把审核通过的 HTTPS 飞书表单 URL 写进 config/site.json 的 diagnose_form_url；目前故意留空。留空时公开页面显示禁用按钮「表单即将开放」。不要在配置文件存飞书密钥、用户信息或任何表单提交结果。

## 九个字段（最多 10 个）
| 序号 | 字段 | 飞书题型 | 必填 | 说明 |
|---|---|---|---|---|
| 1 | 项目名称 | 单行文本 | 是 | 仅填项目名 |
| 2 | 一句话（给谁省什么） | 多行文本 | 是 | 目标用户与节省时间或成本 |
| 3 | 项目链接 | URL | 是 | 演示页或仓库 |
| 4 | 当前进度 | 单选 | 是 | 想法 / demo / 可用 / 已上线 |
| 5 | 海外同类付费证据链接 | URL | 否 | 公开 A/B 级证据页面，选填 |
| 6 | 目标用户在哪 | 多行文本 | 是 | 社区、关键词、群或渠道 |
| 7 | 已有收入 | 单选 | 是 | 0 / 有但<$100 / ≥$100 |
| 8 | 最想解决的卡点 | 多行文本 | 是 | 只描述当前一个最大障碍 |
| 9 | 联系方式（微信或邮箱） | 单行文本 | 是 | 回复诊断用，明确使用目的 |

不另收身份证、支付凭证、银行卡、完整客户名单或私人密钥。

## 提交后的自动回复（原样设置）
> 已收到，见势会在 7 天内回复诊断结果。

如无法兑现该响应窗口，应先暂停表单收集并更新用户告知。

## 上线检查
- 先用测试表单链接核对题型、单选选项、必填和自动回复。
- 只把真实飞书表单 HTTPS 链接配置到 diagnose_form_url。
- 链接为空或不符合飞书官方域名时，T11 页面不开放可点 CTA；绝不使用测试假链接。
- 点击站外 CTA 沿用站点既有 SOURCE_OUTBOUND_CLICK 分析代码（仅在已有统计开启且未选择退出时发送），不引入新统计 SDK。
