# 见势 F2.1｜G2-B 四板块可执行内容工作流验收

日期：2026-10-12。以 G2-A 已上线内容发现中心为基线，仅新增**公开编辑性内容和浏览器本地交互**；不新建账号功能、订单、作品提交、真实课程、收费或采集任务。

## 交付清单

1. **四个企业方案详情页**（电商视觉、视频短片、企业自动化、出海本地化）：增加各自不同的最小练习案例，每个有 3 个具体步骤、人工复核边界和本地需求整理器入口。这是原创教学练习，不是实际客户交付或案例证明。
2. **商机大厅**：需求准备完整度 6 项清单。用户可自主勾选、查看即时完成度和重置，不上传任何需求内容，不创建订单。
3. **人才与服务商**：作品集公开前 6 项自检，区分练习/真实商业成果、素材和作品公开许可，不申请入驻或上传档案。
4. **AIGC 学院**：5 个内容方向，分别包含明确的准备条件和 3 项可独立完成的练习。选择后只在当前页面切换相应练习卡片；没有虚构视频、讲师、付费课程、学员、学习成绩。
5. 复用 `scripts/release/f21_g2b_guided_actions.py`，渲染时写入既有 8 个内容页的 7 个详细页面；`solutions/` 目录沿用原有搜索功能。

## 数据与安全

- 前端 JS 只查询本页 DOM、调整复选框与文字显示；无 `fetch`、存储、Cookie、分析埋点、外部 SDK 或网络访问。清空与页面刷新不保留选择。
- 禁止将用户勾选结果作为“审核通过、真实交易、完成课程”的证明。
- 所有输出使用固定、经审阅的中文文本，不读取私有 Artifact、用户数据、生产 CMS 或未知外链。
- 不改 `JianShi Static Snapshot` 的四个 UTC schedule（00:55/06:55/12:55/18:55）、日 claim 或 HN7/RSS1/GitHub2 限额。
- Supabase Auth、CMS、撮合与支付保持关闭；Staging A/B 测试与本批公开页面分离。

## 测试矩阵

- `tests/test_f21_g2b_guided_workflows.py`：内容数量、固定允许场景、页面输出结构、无敏感字段、无远程调用。
- Node VM 执行 **真实交互脚本**：复选框变更、完成状态、重置与焦点恢复、学院切换、互不干扰。
