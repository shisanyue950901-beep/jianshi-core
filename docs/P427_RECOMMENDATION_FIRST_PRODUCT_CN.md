# P4.27｜从研究网站改成先给推荐的项目发现入口

用户原话：我真不会用我们的网站。我是来找项目、找推荐项目的，最好已验证后直接推荐。

## 核心改动
首页第一屏直接告诉用户：目前有3个具有可归属历史经营证据的案例，其中2个适合优先研究的业务方向，0个已证明新创业者可以直接投入并复制成功的项目。
优先研究01 Carrd：细分人群轻量建站工具；优先研究02 Plausible：网站统计订阅服务；标杆03 NerdWallet：成熟金融内容与比较平台，不建议个人照搬。
每条显示为什么看、适合谁研究、主要不确定性、下一步如何小成本核实、历史经营原始证据和来源。第一步属于研究建议，不是已核实创业收益。

## 发布与事实合同
证据等级L3/L4说明原企业历史经营披露，不等于可复制创业项目，更不保证新进入者获客、成本或利润。首页明确展示直接可启动且完整验证的项目为0，不编造启动预算与收入。
页面从经过严格收录的项目台账和来源约束的证据摘要自动生成，新增项目没有L3/L4不能进入公开案例，未获得进一步落地验证不能标为直接创业推荐。
代码脚本 scripts/release/p427_recommendation_first.py 注入到现有 web/dist 首页首屏，原有3D图环、8图、双主题、证据页面和技术研究资料保留在次级阅读层。
保持单style、单script、8张WebP与小于260000 UTF-8字节要求，GitHub CI通过后发布；浏览器/CDN实地验收仍独立进行。
本轮不用 TinyFish 付费浏览器、不修改 Supabase Production、Cloudflare套餐，不合并历史PR#52。
正式可操作创业推荐的下一步需要验证目标客户、渠道、产品门槛、启动资源和第一笔付费，而不只是原公司的历史财务。
