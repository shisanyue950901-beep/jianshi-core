# 见势 P4.21｜商业模式对比可读性及选择按钮对比度修复

## 用户问题（截图核验）
- 旧选择器选中态 CSS 为 `background:var(--ink);color:#000`。在默认浅色主题下 `--ink=#202823`，造成深底黑字，按钮内容难以识别。
- 对比表按五个长文字行展开，缺乏“先看结论”的摘要，用户不知道优先关注哪项差别。

## 实施
1. 已选按钮增加 `✓ 已选 · 项目名称`，未选显示 `＋ 名称`；选择状态 `aria-pressed`、易懂 `aria-label` 同步，保留最多三种、可点击取消。
2. 选择器使用浅色／深色共同生效的 `var(--ink)` 深浅文字与低饱和 `var(--accent)` 背景、加粗外框，不再依赖固定黑色文字；键盘焦点外框醒目。
3. 对比摘要默认展示 2–3 个信息块，每块说明：商业模式、**主要收入**、**主要工作**、项目描述；文字源自现有六种模式的公开编辑内容，不推断利润、难度评分或实际收入表现。
4. 原长表改为「展开完整五维对照」，五维顺序调整为：**收费方式 → 提供什么 → 客户是谁 → 经营环节 → 涉及成本**。首行着色，行标签在横向滚动时保持可见。
5. 760px 以下摘要改为单列，防止长中文挤压。保留横向可滚动的语义表格、ARIA 状态提示。

## 不变的边界
- 20 具名项目、6 商业模式、时间核验榜、来源说明、浅/深主题、8 张 3D WebP 与原交互均不变。
- 继续一份单 HTML、一个 style 与一个 script；真实项目的利润和营业额仍不做未经核实的承诺。
- 本版需要约 3KB UI 增量，**单文件过渡预算由 255,000 调为 260,000 UTF-8 字节**，源文件和发布注入后的 `web/dist/index.html` 都必须小于上限。后续扩容仍优先实施拆分数据/分页，不允许无上限增加内联数据。
- 不调用 TinyFish 付费浏览器；不改变 Cloudflare Pages/Workers 设置、计费、Supabase Production/Auth/RLS，遗留 PR #52 维持未合并。

## 验收
- GitHub CI 全套测试、JS Node `--check`、8 图/安全标记、255KB→260KB 过渡预算回归。
- 比较模块检查：默认两项可读、选中边框和 ✓ 标识、最多三项、更换选项后摘要即时更新、取消到一项时摘要/长表关闭，完整五维表可通过键盘展开。
- 真机手机浏览器、色彩对比的自动视觉报告、Cloudflare CDN 独立浏览器验收 **未执行时必须明确 PENDING**。
