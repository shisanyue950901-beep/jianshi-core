# F2.1-04｜内容生产、素材版权与合成测试工厂

状态：CONTENT_FACTORY_CONTRACT，第一轮产出模板与验收数据合同。

## 1. 编辑生产流程

选题（目标用户+搜索意图）→ 建立来源记录 → 编写原创文字/图片/视频 → 事实核对 → 版权与隐私审计 → 内容审核 → staging 渲染 → 人工终审 → 公开发布 → 定期复核/撤回。
所有内容版本至少包含：编辑、审核人、发布时间、来源日期、媒体权属和变更摘要；来源失效进入复核队列，不自动继续宣称“已验证”。

## 2. 各板块最低内容合同

| 板块 | 内容结构与验收重点 |
|---|---|
| 商业机会 | 项目类型、来源、原始期间、模式、可核实证据和缺口，不能将行业挂牌算成具名项目收益 |
| 企业方案 | 适用企业、问题、输入、步骤、交付物、验收规则、隐私/版权边界 |
| 商机大厅 | 只展示经过企业认证及审核的真实公开摘要；无商单时展示诚实空状态 |
| 人才与作品 | 技能、真实贡献、作品类别、授权与审核；不公开未经允许的联系方式 |
| AIGC 学院 | 大纲、前置知识、分节练习、真实自制视频、作业、来源/版权和更新记录 |
| 资源工具 | 官方地址、用途、可用性、服务条款与许可标签；定期核对失效链接 |
| 活动 | 真实时间地点、主办方、报名条款和取消规则；没有则不展示虚构活动 |

首期编辑目标仅作为内部待办：12 个方案指南、4 个专题、约 30 个经核验工具、3 条课程路线的样板课程；对外只有实际审核后才能展示统计数量。

## 3. 编辑质量评分与阻断条件

事实与来源25、实用价值25、结构可读15、版权原创15、媒体体验10、时效维护10，共100；建议 85 分发布，同时来源、版权、隐私必须单项 PASS。
任何虚构企业、虚构订单、未授权真实作品、敏感信息外泄、捏造收入或课程数，直接 FAIL。
AI 图片标“概念视觉”，不得作为真实商业交付；课程录屏、声音、音乐和模型使用许可均保留权属清单。

## 4. 内容测试工厂与隔离

本地：只使用 TEST_ / SYNTHETIC_ 前缀的合成企业 A/B、创作者 A/B、课程与订单，禁止使用真实证件、邮箱、电话和客户资料。
staging：独立测试身份、组织和资源，验证编辑到审批再到公开投影全路径；测试内容不能经任何构建作业进入 production。
生产：只接受经内容质量、权限和版权审核的资源；禁止测试用例、脚手架、私有文本或未经核实的数字。
标准样本覆盖：正常内容、空内容、超长标题、图片丢失、视频断流、重复投稿、失效来源、审稿驳回、权限撤回、版权投诉与紧急下架。

## 5. 质量看板数据口径

记录有审核证据的内容数、待审数、驳回原因、错链率、可访问率、课程完成与作业达标（上线后才采集），禁止用开发环境样本充当活跃用户、成交或收入。分析指标与用户个人隐私必须最小化采集。
