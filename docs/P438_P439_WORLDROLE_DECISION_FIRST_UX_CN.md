## 范围与冻结

**P4.38 已实施**：`config/p438_public_ux_contract.json` 和 `scripts/release/p438_public_ux_contract.py` 形成正式公开 UX 字段、页面信息架构和统计指标的 fail-closed 口径；基于实际**已审公司证据**、一人创业适配规则和已有六类商业模式推算 `approved_cases=3`、`verified_launch=0`、`business_models=6`。不是从临时 HTTP 抓取条数或10种登记来源硬编运营指标。缺少来源期间、身份不吻合、重复案例或把历史 ARR 自行改成“直接创业可行”时构建失败。

**P4.39 已实施**：在既有 `scripts/release/p427_recommendation_first.py` 维护单一首页生成入口，替换首屏标题与主要 CTA、增加三条非 AI 的任务选择路径、仅显示有来源的三个数字，并将主菜单缩减为发现项目 / 商业模式 / 方法说明。八张 3D WebP/可拖拽摄影环/灯箱/开屏跳过/深浅主题及低动态偏好保持原样。绝不长期手工修改构建产物 `web/dist/index.html`，由现有 `p412_build_public.py` 统一安全构建。首页链接不改动静态证据目录路由。

**明确不在本轮**：不声称访客使用情况，不创建假的上次刷新时刻，不复制 WorldRole 原画面或仓库源代码，不引入需要 API 花费的AI，不增加未审项目，不做“创业成功概率”，不改变真实来源抓取时间表、Supabase Production/Cloudflare部署规则、计费或历史未合并PR。P4.41 真正资金/技能个性化排序还未实现，因此首页的“根据我的条件筛选”目前是**研究目标选择路径**，不是三问算法。

## WorldRole 视频的真实启发 vs 本站独立设计

**来自视频的观察**：大留白、单一结果型主标题、三类快捷入口、明确数量及当天更新时间。**不能由视频证实**：其完整后台、注册、AI 结果、筛选逻辑、移动端。WorldRole 的公开 MCP Repo 有多来源/AI 工作流描述，但不等于视频站点已逐项上线。

**本项目独立设计**：保持我们的黑底/暖白纸感双主题、Playfair Display + Inter、3D档案展厅；将“找到值得你验证的生意。”放到推荐首屏；用来源约束的真实数值和可以操作的 CTA 代替 WorldRole 的岗位数量与“每5分钟更新”声称。

## 公开数据模型与证据界限

完整合同见 `config/p438_public_ux_contract.json`：

| 层 | 字段或等级 | 显示规则 |
|---|---|---|
| 基本身份 | 公司品牌、已审ID、主体归属 | 必须归属于已审案例才能公开 |
| 经营原始证据 | 来源网址/类别、历史期间、监管申报或自述身份、主张及限制 | 必须保留出处、报告时段及非当前经营保证 |
| 一人创业适配 | `TEST_IDEA_ONLY / SKILL_GATED / NOT_SOLO_STARTUP` | 用户目标假设，不是创业成功认证 |
| 验证门禁 | `ready_for_launch=false`，独立付费/成本/获客证明不足 | **当前已验证可直接启动=0**，不能手工更改 |
| 商业模式 | `config/p412a_user_product_model.json.business_models` 的6个独立ID | 教育分类，不是6家披露盈利的公司 |
| 私有发现数据 | HN讨论链接、RSS线索、源访问矩阵、GitHub技术状态、原始内部报告 | 不得拿私有发现数量冒充已审案例、也不向公网泄漏内部细节 |

`scripts/release/p438_public_ux_contract.py` 直接按上述三份已有可审核配置计算。公司证据需 `https://` 来源、合法三种 L3/L4 来源类型、有效的期间与长文本经营主张。新添17个未审核具名候选时会 fail-closed，而不是悄悄更新首页统计。

1. 纯源代码计数验证：3公开/0可直接启动/6模式来自不同明确记录，而非魔法数字。
2. 旧 `p427` 回归和新 `test_p438_p439_public_ux.py` 负向测试；`python -m unittest discover -s tests -v` 全量 PASS 才合并。

6. GitHub CI和静态构建 PASS≠Cloudflare真实浏览器/CDN或手机真机体验 PASS；真实LCP、CLS、页面跳转应单独验收。
7. 现有 HN/RSS/GitHub 定时API硬限额保持不变；禁止新增日常高频任务、受限平台抓取或Production数据写入。
