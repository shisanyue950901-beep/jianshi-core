# 见势｜三份真实公司案例详情页：先看答案，更多资料再展开

2026-10-13 · B1 下一批实际交付 · 基于已冻结 B0 个人创业主线、Super-i 卡片→详情结构和原创蓝紫色视觉母版。

## 用户任务

用户点进 Carrd、Plausible、NerdWallet 后，**不应该再次读一遍官网/经营依据/成本/风险的长报告才能知道适不适合研究**。页面首先回答：做什么、谁真正付款、怎么收费、哪些仍未知；然后显示能否一人尝试及具体第一步。只有当用户愿意深挖时，再主动展开证据与验证工作单。

## 本批具体施工

1. 三份既有具名案例详情的「30 秒看懂」卡显示 **做什么 / 谁付钱 / 怎么收费 / 什么还不确定**，其中收费人是已有人工核对 `PAYING_PARTIES` 的 Carrd/Plausible/NerdWallet，不将 NerdWallet 读者错当广告付款方。
2. 原 P4.40 决策卡的**真实结论和专属第一步保持在首屏内容**；所需技能、成本、原公司历史资料、三步核实过程放进**默认关闭**的原生 HTML `details`，无需 JavaScript。
3. 原先详情页完整的**四项经营状态、来源链、经营说明、成本、未知项、历史披露、下一步研究**统一放在独立、默认关闭的「查看资料来源、成本和更多风险说明」，内容原样保留。摘要仍可直接点击原始经营依据，不必展开才能看到来源链接。
4. 原 P4.40 工作单是用户主动使用的研究工具。四步工作单保留在独立、默认关闭的「想自己验证？打开四步工作单」中，链接跳转到可操作的 summary 容器，用户自行点击展开；打印时可主动展开工作单后打印。
5. 视觉上从旧版淡绿/米白分裂风格，与冻结的见势蓝紫/浅色体系对齐；保持 dark mode，窄屏单列、焦点样式、无新外部字体或网络依赖。
6. 不删除原商业事实及链接，不更换历史经营数据、来源、准入、项目数，不增加任何尚未验证的商业数字。三份案例仍是**历史经营研究案例**，**不是已核实能盈利的三个新创业项目**。
7. 不开放后台登录、CMS、商机、撮合、支付、用户信息提交，不接触数据库和 P4.41 原定时及采集开销。
