# 见势 P4.20｜时间研究榜与来源说明（2026-10-09）

## 为什么从卡片墙转为榜单

用户首次访问的第一个问题是“先看哪个项目？可信来源在哪里？”而不是“有多少卡片”。P4.20 用一次最多 **10 条**的单列研究榜替代连续的大块卡片墙。原有 8 张 3D 封面照常保留在首屏，后面的图片画廊折叠，按需展开；完整资料并未删除。

## 榜单必须遵守的事实合同

- 名称：**最近核验榜**。排名定义为：**资料最后核验日期倒序，同日按编辑收录顺序**。
- 今日、本周、本月只筛选**核验日期**。当前使用北京时间（Asia/Shanghai），本周从周一开始，按日历月计算，不是滚动 7 天或 30 天。
- 本版**没有热度指标**，不显示“热榜”“涨幅”“收益率”“项目成交热度”等无法证实的数字。列表前方 01/02/03 只是序号，不代表销售排名。
- P4.13 10 项的 `verified_on=2026-10-09` 是该批编辑核验日期；P4.15 8 项逐条 `verifiedOn=2026-10-09`。首批 18 项于同日核验，因此三个时间窗在 2026-10-09 可能完全重合，**这不意味着每天都有新项目**。
- Easlo、Louise Lennox 两个原有 3D 封面项目缺少统一的逐项核验日期，暂留在封面展示而不编造时间戳；可继续打开其真实项目详情。
- 新日无核验数据时应显示该时间窗 0 项，不能自动使用旧记录冒充今日发现。

## 项目来源与依据

- 列表显示“信息依据：官方公开页面”及两条独立外链：
  1. **官方网站**：业务主体公开主页；
  2. **核验依据**：商品、产品、定价、文档或服务页面，证明对应产品/公开收费方式存在。
- 这些网站证明**公开商品或服务的存在**，并不证明实际销售额、净利润、访问量、增长率或真实热度。
- **首次发现渠道未逐项记录**，不能将查证渠道伪称为项目发现途径。不存在对受保护商业挂牌的可识别重建。
- 对来源外链要求 HTTPS、禁止 URL 用户名/密码、`target=_blank` 同时 `rel=noopener noreferrer`。

## 功能与保留项

- 20 具名项目和 6 商业模式保留；研究榜展示 18 个有日期的项目，默认 10 条，按需“查看更多”。
- 旧搜索、项目类型、三维商业筛选、案例详情、官网双外链、比较模块保留。
- P4.18/P4.19 字体和留白继续保留，浅色为默认、深色可切换、8 张 3D 封面与原动画不改。
- 时间按钮与旧内容类别是**不同维度**：时间仅过滤研究榜；模式分类仍展示模式介绍。

## 技术预算与下一阶段

此前单 HTML 目标严格小于 250000 字节。由于增加真实可解释的榜单、来源和时间逻辑，本版**明确提出将临时预算上限调为 255000 字节**；仍维持单一 `<style>`、单一 `<script>`、8 张 WebP 和 `web/dist` 公共发布目录，并保留构建后体积校验。该调整是明确记录的性能预算变更，非安全扫描或隐私合同放松。

这是仅适用于当前 20 项的小规模过渡方案。要扩容到 100/1000 项，下一阶段必须把公开档案、核验事件和显示层抽离到**可审计 JSON / 分页索引**，按日期保留真实核验记录，停止把每条记录永久内嵌在巨大 HTML 中。若希望称为“今日热门”，必须另行取得有许可证、可重现的浏览/讨论/趋势数据，并公开排序公式与更新时间。
