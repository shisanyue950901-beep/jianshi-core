# 见势 JIANSHI｜G2-C 跨板块阅读路径与内容发布质量门禁

日期：2026-10-12。建设对象是已上线的静态公共站点。不触碰生产账号、CMS 或私有采集。

## 实际交付

- **9 个公开页面**（4 个企业方案详情、企业方案总览、商机大厅、人才、AIGC 学院、内容发现中心）各增加 **3 个**按当前内容人工撰写的后续建议，共 27 条站内关联链接。
- 每条建议提供用户能立即执行的实际下一步和对应公开链接，不将规划中的课程、服务商、订单写成已经开放或成交。
- 移动端使用单列相关推荐卡片，触摸区有明确文本和留白，键盘可见焦点、减少动画偏好得到尊重；不增加网络请求、Cookie、埋点或新的客户端 JavaScript。
- 新增 `scripts/release/f21_g2c_related_quality.py`：人工审核链接白名单与发布时的**只读机械质量门禁**。检查 9 页各有唯一的 `main`、标题、描述、canonical、viewport、H1、相关模块、恰好 3 条指定关联链接，且每个目标都有存在的可阅读 `index.html`。
- 不会把页面文本长度、CSS 数量或链接存在性冒充事实真实性、版权许可、财务数据审核。编辑质量标准仍按现有 100 分规则，由人对事实、版权和隐私作签核。
- 原内容发现目录仍保持 17 个已公开条目，本批不是新增项目或商单。原有正式 Sitemap 目标数量不调整。

## 强制失败场景

本批单元测试会模拟删除一个链接目标、把目标换成无正文的占位页、以及破坏推荐区域结构；应一律阻断 `audit_release`。实际发布必须在公共内容构建完成后执行 `audit_g2c_release(OUTPUT)`。

## 严格验收标准

1. PR 中全部测试和运行合同 PASS。
2. 合入 main 后 `event=push` 的 Static Snapshot **公开静态构建** PASS，不得将其当作 `event=schedule` 的真实来源采集。
3. Cloudflare 免费域名上 9 个 URL 真实 HTTP 200、相关内容 HTML 标记与不同页面目标匹配。
4. 浏览器移动端实际视觉/交互若未使用真实设备测试，仍标记 NOT_TESTED，不能用代码覆盖宣称已做真机验收。
5. 认证、CMS、撮合、支付仍关闭，P4.41 四个 UTC 调度时段与 HN/RSS/GitHub 请求次数未更改。
