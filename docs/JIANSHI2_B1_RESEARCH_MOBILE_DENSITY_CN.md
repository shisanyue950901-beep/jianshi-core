# 见势 B1｜六种生意页面第二轮减负与手机布局约束

状态：源码已施工，必须经过 PR / main 全量 CI、静态快照、线上正文核验后才允许标记代码交付。日期：2026-10-13。

## 目的

遵循已冻结的 B0 双线商业逻辑（个人创业机会为主、企业 AI 为第二线）与见势原创视觉母版。上次已经把六类商业模式的说明放到统计资料前面；这次进一步删掉容易误导和浪费屏幕空间的重复信息。

### 实际改动

- 六类详情中原本重复且无意义的第四块「适合先做什么：先了解客户需求，别急着投入」删除。现在三块只讲 **谁付钱／怎么赚钱／需要什么**，下面保留每一类**独有的第一步**。
- 七个研究页面旧顶部菜单由「项目研究库 / 趋势信号 / 数据口径 / 隐私」精简为 **「找创业项目 / 六种生意」**，使用户从详情返回创业主路径更容易。隐私政策未删除；全站既有隐私 URL 保持有效，只是不占据这条使用路径的头部主导航。
- 历史样本展开按钮文案缩短为「想看历史数据？点这里展开」，保持原生 HTML `details/summary`：鼠标、键盘可操作，无 JS 依赖，默认关闭。原有审计章节、来源限制、统计、链接与 Cloudflare 归档样本数校验继续保留。
- 增加窄屏减少卡片边距、单列规则、可聚焦展开按钮和打印时仅在详情实际展开才打印历史统计的 CSS。此 CSS 仅是静态结构/规则验收，**不代表已通过手机 Safari 或真实打印机视觉测试**。
- 页脚由「公开商业数据研究工具」改为「发现生意，理解怎么赚钱」，避免工程化定位压过主业务，保留收益不保证声明。
- 不改变六类业务描述、真实付款方、财务数字、历史样本数量、来源审计、noindex、canonical、商业模式类别或 P4.41 的采集计划。

### 交付和验收分层

1. **源码**：七页均有两个有效主导航、三项商业事实、案例独有第一步；不包含重复「适合先做什么」；历史样本使用默认关闭的可键盘操作 `details/summary`，无表单、网络采集或账号启用。
2. **回归**：原有 599 项以上测试和 Cloudflare 已提交快照必须通过；改动仅在 `scripts/release/p449_plain_business_models.py` 和其测试，不准直接编辑 `web/dist` 等构建产物。
3. **部署**：GitHub 主分支 CI + Static Snapshot 均成功，私有四步采集全部 SKIPPED；正式 CDN 的七页短导航、折叠按钮文案与风险说明逐页可读取。
4. **未验证**：在 TinyFish 额度不可用时，实际浏览器截图、390px/1440px 溢出、真实点击和打印测试标为 NOT_TESTED。自动抓取纯文本不能证明 `details` 浏览器视觉状态，也不能代替真人研究。
5. **真人目标**：至少五名创业意向用户能在不看工程说明的情况下辨认收款方、收入形式与第一步；样本尚未开展，不夸大为实际留存/付费。

后续用户体验的改进只围绕“项目好找、价值好懂、入口好点”，不要新增第二套分类系统、平台人数、虚构热门、支付和企业撮合。
