# 见势 F2.1｜G1-G 第一批：移动导航与浏览器验收

日期：2026-10-11。工程范围：只有现有静态首页移动端导航体验、真实 JS 交互回归和 F2.1 验收记录。

## 一、原问题的精确定义

2026-10-11 远端浏览器对生产首页和企业方案目录的导航及方案筛选做了真实点击验证；链接、4→1→4 搜索、企业与创作者本地草稿均正常。**该浏览器没有切换到手机视口，因此不能得出“移动菜单不存在”或“真实手机交互通过”的结论。**

源码已存在单一统一首页、 `<details class="j2-mobile">`、 `aria-label="展开主要导航"` 和 `@media(max-width:1080px)` 的显隐规则。此次不新增第二套页面，不恢复已废弃旧 3D ring，不改动已审核业务板块。

## 二、G1-G 此次实施

- `scripts/release/p445_unified_home.py`：补强小于 400px 的品牌/菜单间距、焦点可见性、最大菜单高度及局部纵向滚动，保持 1080px 断点不变。
- 移动端菜单行为：点击菜单内导航项自动关闭；按 Esc 关闭并归还焦点；点击菜单外部关闭；视口回到桌面时自动关闭。没有 cookie、网络请求和用户信息收集。
- 延续旧 hash 书签兼容和唯一 inline script，保持相同主页面及搜索/内容导航结构。
- `tests/test_f21_g1g_mobile_nav.py`：用 Python 生成**真正的首页静态 HTML**，对导航项、片段目标、断点、焦点 CSS、安全预算做检查；用 Node VM + 模拟 DOM 执行首页实际内联 JS，验证 7 种交互和历史 hash 重定向。
