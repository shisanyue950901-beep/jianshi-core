# 见势 B1｜从首页到找项目与公司研究的视觉统一（2026-10-14）

## 用户任务

登录网站后希望视觉有品牌感，同时真正用户任务是「发现一个创业方向 → 看谁付费及收费模式 → 检查公司证据 → 形成下一步核查计划」。本轮统一入口间的视觉，而不是新增后端/数据/交易能力。

## 已实现

- /discover/：深蓝蓝紫渐变和细网格，三步轻量研究引导，输入框、分类筛选和卡片套用首页蓝紫结构；所有 17 项内容及原默认 9 个创业方向未变，搜索、空状态、清除筛选继续可用。
- /projects/：3 家经过来源准入的历史公司案例，首屏增加同色系信息卡和可读的研究状态，下面原 3 张案例卡调整字体、间距、边框、标签和按钮；仍明确 0 个可验证直接复制盈利项目，决不把历史公司经营案例包装成新手赚钱机会。
- /projects/carrd/ 等详情页：保留每家公司原证据/来源/时间/风险/四步工作单，调整概要与数据区分层、标题和按钮样式；无电子邮件输入、无注册或付费动作。
- 不改变原 /account/ 的禁止注册状态、独立 /account/preview/ 的无表单预览和 Auth Gate。
- CSS 全部在对应源构建脚本修改，不直接更改 web/dist、不导入第三方模板、字体/图片/动效外链。
