# JIANSHI 2.0｜产品与视觉冻结基线 F1（2026-10-11）

> 状态：DESIGN_FREEZE_F1 / PREVIEW_ONLY / PRODUCTION_UNCHANGED。文档冻结产品方向与首版设计，不等于数据库、交易与服务端能力已上线。

## 1. 品牌定位

**见势 JIANSHI 2.0**：AI 商业机会、技能学习与企业解决方案撮合平台。

主张：**发现机会 · 掌握 AI · 对接需求 · 创造价值**。

### 核心闭环

- 个人：查看已审核商业机会 → 学习 AIGC → 完成作品 → 公开经授权的创作者资料 → 申请企业商单 → 合作交付；
- 企业：浏览 AI 解决方案 → 描述业务问题 → 企业认证 → 人工审核需求 → 选择创作者 / 服务商 → 合作交付；
- 平台：内容审核、许可审查、账户与企业角色隔离、人工撮合与纠纷处置。

## 2. 页面与功能范围

| 模块 | V1 高保真预览 | 后续上线阶段 |
| --- | --- | --- |
| 商业机会库 | 仅展示三条原本已审的历史案例；链接回正式研究目录 | V1 延续现有来源审查与项目卡片 |
| 企业解决方案 | 4 类静态场景：电商视觉、品牌视频、企业智能体、出海营销；明确“方向示意” | V2 方案详情、需求采集、实际交付案例审核 |
| 商机大厅 | 明确空状态，无虚构企业、预算、订单与竞标量 | V2 企业认证、审核、发布、申请与匹配 |
| 人才与服务商 | 占位说明、不可提交信息 | V2 技能、作品集、授权联系方式、申请 |
| AIGC 学院 | 课程能力预留与内容规划，无虚构课程数或用户数 | V3 自主制作及授权视频上传、章节、进度、作业 |
| AI 智能匹配 | V1 不开放，不能声称已有线上匹配模型 | V4 可解释的需求与人才匹配，人工复核 |

普通用户与 AI 创作者复用账号；企业作为独立主体认证。企业成员权限与个人简历、作品、联系方式均最小授权。

## 3. UI / 动效冻结

- 视觉参考：Super-i 的视觉层级、内容大卡片、渐变、互动节奏；**不复用其品牌、图片、源代码**。
- 见势独立设计：深色石墨首页、蓝紫渐变主视觉、轻玻璃质感、浅色内容工作台、清晰的中文排版。
- 首屏优先描述用户收益，五个入口：商业机会库／企业解决方案／商机大厅／人才与服务商／AI 学院。
- 手机视图为单列 / 双列自适应，菜单支持展开、Esc 关闭；内容搜索只筛选现有已审案例。
- 动效：卡片 hover、背景光晕、滚动渐现；支持 `prefers-reduced-motion`，不得阻碍可读性、交互或滚动。
- 原创图片：使用图片生成制作的概念视觉，压缩成 WebP 以内嵌 data URI 嵌入预览 HTML，**不作为经营证据**、不冒充真实合作项目。
- 图片说明、组件 CTA、空状态均需真实反映功能开放程度。

## 4. 实施与生产隔离

- 可用预览：`web/prototypes/jianshi2-v1/index.html`，**独立单文件**，CSS、JS、WebP 内嵌，可本地打开。
- 构建正式首页的唯一入口仍是 `scripts/release/p412_build_public.py` 与其原有上游 `web/build.py`。不要直接编辑 `web/dist/index.html`、`dist/`、`public/` 或根目录渲染镜像。
- 本次不修改 `.github/workflows/publish-static.yml`、`scripts/research/`、`supabase/`、`db/`，不增加外部 API 访问与定时任务。
- 本次 **不部署**；用户视觉验收后，按原生产源构建器进行受控整合，并进行全量测试、隐私泄漏审计、正式路由兼容与真实浏览器验收。

## 5. V1 验收门禁

1. 原有 3 个已审历史案例：Carrd、Plausible、NerdWallet；不再编造业绩和“已验证可创业”指标。
2. 无虚构企业需求、服务商、课程、用户人数、GMV、财务收入和推荐分数。
3. 无账号表单、支付及真实企业信息提交接口；预览可操作元素仅导航、菜单和前端案例筛选。
4. 设计稿含 HTML 内嵌原创 WebP，主视觉注明“概念视觉非真实项目案例”。
5. 在 1440px 与 390px 的 Chromium 中：无横向溢出、无 JS 异常，菜单 Escape 可关闭，筛选可恢复。测试截图属于浏览器模拟，不代替真机 Safari 验收。
6. GitHub CI 需全量 PASS；PR 审核前只提供独立预览，不修改生产路径。

## 7. 2026-10-13 B0 用户确认的优先级补充（不覆盖本 F1 历史版本）
