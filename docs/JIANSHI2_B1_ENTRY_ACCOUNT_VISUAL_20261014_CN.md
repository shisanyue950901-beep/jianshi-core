# 见势 B1｜入站首屏与邮箱注册界面升级（2026-10-14）

## 用户关注

进入见势，应有更好的科技感、品牌辨识度和清晰的找项目入口。注册页应与首页采用同一套蓝紫和深蓝视觉体系。

## 施工范围

- 首页保留创业研究主线、三个源审计具名案例与六类商业模式，仅升级蓝紫光晕、低对比网格、渐变标题、三步研究路径，以及研究资料视觉卡片。
- 首屏项目卡片增强描边、间距、焦点和悬停效果，不增加视频、复杂 3D、假客户案例或夸大统计，不使用第三方付费素材或提示词。
- /account/ 改为双栏品牌欢迎页。当前生产 Auth 关闭：仅展示不可输入、不可提交的邮箱注册/登录界面预览；没有真正的邮箱输入框、form 或后端发送。保留 noindex,nofollow 和“先去发现项目”真实链接。
- Auth 双钥匙开闸后才会出现原 Magic Link 邮箱登录/首次注册表单，保留原收藏、观察、提醒、退出与数据清空 DOM 契约，无新密码注册、短信、第三方登录或数据库。
- 首页在 Auth 尚未开放时不增加“登录/注册”导航链接。通过直接访问 /account/ 审核视觉效果。

## 验收

分支 CI、新安全回归测试、390px 和 1440px 真 Chromium 截图与不可提交按钮测试必须 PASS；主分支静态快照与独立浏览器 QA PASS；push 私有采集四项 SKIPPED，生产数据库不写入。

NOT_TESTED：实际 SMTP 邮箱送达、账户创建和登录端到端、A/B JWT 账户隔离、真实硬件和真人用户测试。界面完成不代表认证开闸完成。
