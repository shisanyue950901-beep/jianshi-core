# 见势 R6｜公开数据中文化展示

## 用户界面规则
- GitHub 仓库名保留原名，避免失去唯一标识。
- 技术项目简介默认展示中文摘要，不默认展示大段英文原文。
- 编程语言、GitHub、SaaS、LLM、AI Agent 等必要专有名词保留。
- 商业样本默认使用中文结构化标题，不把英文挂牌标题作为主视觉。
- 原始英文描述和标题保留在数据层，供追溯与人工核验。

## 中文摘要来源
- CURATED_R6：人工级中文摘要。
- SOURCE_ZH：原始项目描述本身包含中文。
- RULE_FALLBACK_R6：尚未人工整理时，按发现类别生成中文兜底摘要。

- 公开技术候选：145
- 中文摘要缺失：0
