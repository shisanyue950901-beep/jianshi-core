# 见势 B1｜六种生意模式页面「先说怎么赚钱」改造与验收

日期：2026-10-13｜遵循 B0 商业定位、Super-i 借鉴的「卡片→详情」模式与见势已有原创视觉母版。

## 用户任务

找项目的人不应先看到挂牌利润率、工时中位数和样本统计方法，应先回答：
**卖什么、谁付款、怎么赚钱、需要什么能力、可以先试什么**。

本批只整理原本已经公布的六类**生意模式**：行业软件订阅、跨境细分商品、数字产品、内容推荐、图书出版、专业服务。这六类不是六个已验证能复制盈利的创业项目，也不等于六个有客户和订单的见势商机。

## 已执行的功能变更

1. `/research/` 总览：先展示六张「是什么生意、怎么赚钱」卡片；长篇样本数量、挂牌财务统计及表格保留在一个可展开的「查看历史样本、统计数字与详细说明」里。
2. 六条 `/research/<slug>/` 原详情：首屏统一展示经营模式、实际可能付款方、收费方式、所需能力与**可否定的小验证行动**；完整匿名案例、挂牌统计、披露时效、来源限制、风险边界、相关研究链接保留在可展开内容中。
3. 继续使用原站点 CSS 设计体系、响应式布局和无 JS 的 `<details>` 折叠。页面不会采集、提交、持久化任何用户信息，也没有新增真实创业成功数据。
4. 官网、三份具名历史案例、独立企业 AI 业务线均不改；此前实际已收录的具名历史案例仍为 3，已证实可复制盈利项目仍为 0。
5. 只改变**公开镜像的展示层**：`web/build.py` 仍生成原始研究资料，`p412_build_public.py` 经过原有匿名/安全/路由检查后交由 `p449_plain_business_models.py` 重排。没有修改原始数据源、采集次数、P4.41 计划、数据库或服务器端服务。
6. 不允许以历史挂牌经营数值推断新创业者利润，也不能把市场样本当作已经成交或经过见势独立财务审计的企业。

## 后续清理顺序

1. 根据真实 PC/手机体验核查六种生意卡片是否过长、展开控件是否清楚；如有需要进一步压缩到同屏。
2. 用户能进入 /discover/→/research/<slug>/，不要再新增第三套筛选目录。
3. 企业 AI 第二业务线保持独立，不把此处匿名商业研究自动导流到付费企业撮合。

**原则**：内部研究可以复杂，用户不用先看懂样本统计，照样能理解这个生意如何运作。
