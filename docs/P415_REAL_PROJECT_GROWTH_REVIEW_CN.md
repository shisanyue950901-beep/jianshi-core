## 商业模式与专题方向

建议专题分别研究：
1. **隐私网站统计软件**：Plausible / Fathom，比较浏览量计费、分析仪表盘与数据维护成本。
2. **邮件通讯商业工具**：Buttondown / Kit，比较轻量通讯和完整自动化平台的客户、交付与收入差异。
3. **创作者卖货的底层平台**：Payhip / Gumroad，比较按交易抽成与订阅/费率组合；**平台本身不是数字模板销售者**。
4. **实体品牌的资金占用**：Bellroy / Beardbrand / Ugmonk，比较商品类别、库存、营销与复购条件。
5. **设计服务的团队化**：Designjoy / ManyPixels / Superside，比较任务队列、订阅容量和专业团队成本。
