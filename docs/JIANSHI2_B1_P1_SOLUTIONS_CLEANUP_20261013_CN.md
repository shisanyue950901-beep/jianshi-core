# 见势 B1-P1｜企业 AI 方案页面减负与行动路径（2026-10-13）

## 真实用户任务
一家小商家打开「企业 AI 方案」：不读长篇产品术语，30 秒内找到适合自己的方向，知道可以得到什么参考成果、先准备什么，以及怎样自己做一次低风险测试。

## 按冻结逻辑施工
- 双业务战略不变：**个人创业机会发现是第一业务线**；企业 AI 咨询与试点说明是第二业务线。
- Super-i 只作「分类 → 卡片 → 详情 → 行动」信息架构参考，不复刻其视觉、代码或品牌。
- 继续沿用见势原创石墨深色 + 蓝紫渐变卡片与已有响应式 CSS；不建第三套设计体系。
- 全部四项只是业务场景与参考交付方向：不得暗示已签单、已交付、可购买或保证效果。

## 本次减掉什么
1. 列表首屏标题、说明、跳转按钮、重复不开放提示合并成最简 hero 和一句真实开放状态。
2. 删除「如何写企业需求」三大流程版块和重复「下一步合作」大模块，折叠为一份含三项前置检查的简短提示；保留通往纯本地需求草稿的实际可用链接。
3. 四张卡直接比较「业务问题、适合谁、参考成果、先准备、关键提醒」。卡片预览有编辑锁定的四方案白名单和字段完整性检查。
4. 四个详情优先展示问题、适用、准备材料及可能的成果，然后呈现自主小测试；完整建议实施步骤和质量验收改由原生 details 展开，风险/个人信息提醒仍可见。
5. 与本次五个页面相关的 3 条已存在站内阅读链接改为折叠布局；保留共 27 条关联内容审计、每页三条链接。
6. 方案筛选的「清除筛选」默认隐藏，搜索或选择分类后出现，重置可恢复全部四张卡。
