# 见势 B1-P0｜公司案例列表减负施工记录（2026-10-13）

## 本次只修哪一个实际问题

真实路径：首页「直接看项目」或「按方向找项目」→ 三家真实公司案例 → 详情 → 第一条创业验证行动。

/projects/ 原来仅有三张卡，却还包括搜索框、两种资料排序、长篇自动提炼的证据要点、重复的起步判断/验证缺口、排名编号、分类统计与单独说明区。用户很难迅速判断谁付钱、怎么赚钱、是否值得自己研究。原页面默认按经营披露级别排序，视觉效果也容易误读为项目推荐名次。

## 必须保留的事实及边界

- 三个历史案例不等于三个新创业者已验证盈利的项目；/discover/ 的 17 条公开路由不等于 17 个真实商机。
- NerdWallet 的实际商业付款方是广告及合作伙伴，不能写成站点读者。
- 公司公开标价不等于实际成交；历史财报或公司历史自述不能预测个人收入。
- Staging/Production 登录、CMS、撮合、支付及 P4.41 定时和来源预算均未更改；未访问或修改生产数据库。
