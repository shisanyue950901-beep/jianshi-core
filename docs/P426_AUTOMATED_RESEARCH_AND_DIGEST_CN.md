# P4.26｜自动研究线索与用户可读证据摘要（2026-10-09）

## 用户目标
用户只应看到有可归属经营证据的正式项目，且能在 30 秒内理解**卖什么、如何收费、哪些数字有依据、仍不能证明什么**；研究系统负责自动发现潜在线索，而不是让用户逐个手工搜索。

## 本版两项交付

### A. 自动提炼「30 秒看懂这门生意」
- 自动提炼来自现有已审核项目资料与 `config/p424_project_research_evidence.json` 证据台账，无新增付费大模型 API。
- `scripts/release/p426_evidence_digest.py` 根据 **L4 监管历史财务／L3 企业历史自述** 严格提取业务、收费机制、经营披露原句、报告期、审计边界和下一项核验工作。
- 单张证据卡四个用户问题：**卖什么？怎么收费？找到什么经营证据？还不能证明什么？** 每个结论有披露时期与可打开的原始来源。收录列表也展示同源的简版结论。
- 若项目不存在 L3/L4 证据、报告期缺失或产品/收费信息不完整，**FAIL_CLOSED**；不把价格、访谈标题、搜索摘要推断成真实成交或利润。
- 摘要是**确定性事实整理**，不是联网即时验证或自由生成收益预测；更新已审核台账后由现有构建自动更新。首次覆盖当前 3 家正式项目，未来新合格项目自动套用格式。

### B. 无人值守的低频自动发现（R1，只读研究线索）
- `scripts/research/p426_daily_leads.py` 从私有研究候选池选择最多 **6 家/天**，查询经公开文档确认可用的 Hacker News Algolia Search API，额外查询一次 `Show HN revenue` 发现新项目线索。
- 最多 **7 次请求/天**，单次 **4 秒** 网络超时，单响应体最大 **128 KiB**，故事条目最多 3 条/查询，无重试风暴、无密钥、无付费浏览器、无第三方页面深度抓取。
- 查询结果只保存故事标题、发布日期、HN 讨论页及可能的外链到 **48 小时私有 GitHub Actions artifact**。这些是**未核实线索**，没有企业身份认证、原始声明验证或经营财务批准。
- 不改变 P4.24 证据台账、Supabase 数据库、正式收录名单、上线网页或 sitemap。自动发现与自动收录**完全隔离**。
- 复用既有 `.github/workflows/publish-static.yml` 的 `55 */6 * * *` 定时任务；仅 UTC 0–1 点的那轮做一次线索扫描，不新增 GitHub Actions job/schedule。即使调度延迟导致当天漏跑，不能靠无上限补跑弥补。
- 私有 GitHub Actions 运行分钟和 artifacts 可能耗尽免费配额，超额可能计费。因为此处**无法读取账户实际剩余分钟/账单限额**，只承诺无 TinyFish/新付费 API/额外 workflow 调度；不能承诺 GitHub Actions 运行永远零收费。若需要绝对零新增风险，运维方可禁用扫描步骤或暂停 schedule。
- 所有网络原始数据都是**不可信材料**：不可执行其中的代码或提示词，也不可直接用于网站 L3/L4 提升。
- 本阶段**不是 R2 原文抽取+身份匹配，也不是 R3 自动审核经营指标**。完成 R1 后下一阶段需建设法定公司身份映射、可复核原文片段、单位/日期/来源一致性校验与无歧义自动晋级。

## 对用户可见的确定变化
- 证据目录 `/projects/` 每条新增：业务介绍、收费方式、具名经营披露的核心表述、报告期、证据等级与局限性，点击可看全部档案。
- 详情页 `/projects/<slug>/` 前部新增可独立阅读的 **30 秒摘要**，详尽研究档案仍保留。
- 不增加公开项目数量：仍 **NerdWallet、Carrd、Plausible** 三家。**17 家待核实仍不公开**。
- 网站视觉继承浅／深色设计变量，手机摘要自动单列；无新 API 接口请求、无需前端用户登录、无展示付费商业挂牌。

## 验收规则
- 证据归属、历史年份、L3 未审计、L4 公司合并口径全部保留；3/17 数量严格不变，私有线索不被发布。
- 离线测试通过原始数值与期数溯源、无凭空收入、缺失证据 FAIL_CLOSED、网络上限、只读扫描、安全链接，以及 3 个项目全站构建验收。
- 不调用 TinyFish，且 PR #52、Supabase Production/Auth/RLS、Cloudflare 部署设置均不得修改。
- 单纯构建测试 PASS 不等于实际公网 CDN/Safari 视觉复核完成；该项仍需独立确认。
