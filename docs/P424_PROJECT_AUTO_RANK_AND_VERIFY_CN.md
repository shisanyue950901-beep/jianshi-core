# P4.24｜证据分级自动排序与主动补证（2026-10-09）

## 对用户问题的直接回应
“为什么待核实的不去核实？让我去核实吗？”
核实工作由项目研究流程承担；用户应看到可读结论和原始证据，不应为研究系统手工查询财报、采访和客户资料。项目名下的任何历史数字必须带时点与证据类型。

## 排序的产品定义
排序名称：**证据层级榜**，不是“赚钱排行榜”“创业潜力榜”。
- **L4**：具名公司的历史监管财务申报（例如 NerdWallet 公司 2025 财年 SEC 10-K；仅代表申报期的公司合并数据）。
- **L3**：创始人或企业历史经营自述（Carrd 历史访谈、Plausible 2022 年官方文章）；属于可信署名历史陈述，**未经独立财务审计**。
- **L2**：独立平台对该创作者或产品的归属旁证（Notion / Amazon），不能证明真实销量。
- **L1**：仅已核对该企业的公开产品/服务和收费机制。
- 默认 L4→L1。相同层级按项目 slug 稳定排序，不臆造差异化得分。用户可切换 **待补证据优先（L1→L4）** 作为研究队列；排名明确不反映利润、增长、用户规模或投资价值。
- 构建脚本每次读取配置文件 `config/p424_project_research_evidence.json` 自动计算排序，写入静态 `/projects/`；既有 GitHub Static Snapshot 已按每 6 小时触发，**新证据入库后下一次构建会自动重排**。仅重新构建不会生成新证据。
- 不能凭链接存在提高证据层级：每次等级上调必须有具体、具名可归属的原始资料和不确定性标签。

1. **NerdWallet / L4**。NerdWallet, Inc. 2025 10-K 的公司合并营业收入为 **$836.6 million**，合并净利润 **$48.7 million**，文件 2026-02-25 提交，2025-12-31 截止。出处： https://www.sec.gov/Archives/edgar/data/1625278/000162527826000014/nrds-20251231.htm 。监管历史财务申报，不代表 2026 年最新净利或某条业务线利润。
2. **Carrd / L3**。创始人 AJ 在 SaaS Club 旧访谈自述当时约 **$100K MRR / $1.2M ARR**。出处：https://saasclub.io/podcast/carrd-aj-306/ 。不虚构精确采访日期，不认定经过审计，不当作 2026 年收入。
3. **Plausible / L3**。Plausible 在 2022-06-22 官方文章声明达到 **$1M ARR**，7,000+ 付费用户。出处：https://plausible.io/blog/open-source-saas 。这是公司历史自报，不代表当前数据和独立财务审计。
4. **Easlo / L2**。Notion 官方创作者目录 https://www.notion.com/templates/creators/easlo 支持创作者／商品关系，并不证明成交。
5. **Louise Lennox / L2**。Amazon 官方历史作者案例 https://www.aboutamazon.com/news/books-and-authors/how-these-authors-found-success-with-amazon-kindle-direct-publishing 支持其历史 Kindle Direct Publishing 经历，不得推导当前版税。
6. **其余 15 项 / L1**。目前项目可归属的公开收费页面已存档，但并未取得足够支持经营结果的额外证据。**不因为缺少资料而把收入写成零**。

## 后续持续核实工作
- 核查各个项目所在法律实体，防止同名、品牌与合并母公司的错误关联。
- 优先检索 SEC 10-K/10-Q、可靠公司财报；其次具名创始人自述、原始采访、平台侧商品/作者身份；再看真实客户/续费和独立需求证据。
- 已识别的下一项研究问题保存在 `next_research`，并直接显示在对应项目档案。
- 不可以用匿名行业挂牌财务数据替代某家公司的财报，不得把关键词相似当作身份一致；爬虫只允许合规公开来源，不绕过登录、付费墙或反爬限制。
- 下一阶段需要建立**证据事件自动采集＋去重＋审核/权利门禁**（可以依托现有六小时快照调度但先明确 API 配额），让可确认的新资料定期进入审查队列；自动链接检查仅检查可访问性，不等于验证金额真实性。本版尚未完成“20 家企业经营数字自动全量核实”。
