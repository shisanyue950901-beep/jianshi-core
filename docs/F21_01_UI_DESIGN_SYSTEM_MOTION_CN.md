# F2.1-01｜UI 设计系统与动效验收合同

状态：DESIGN_TOKENS_V1 / G1 第一批；参考 Super-i 的信息架构、封面、筛选与动效层次，但禁止照搬品牌、源代码和作品图片。所有内容真实性高于视觉包装。

## 1. 页面分型与组件

1. 品牌页：深色石墨背景、渐变主视觉，单一主行动、明确用户双角色选择；不得塞入旧 3D 归档。
2. 目录页：吸顶筛选栏、搜索、条件标签、网格/列表切换、分页或加载更多；所有筛选参数可解释。
3. 详情页：封面、标签、正文、交付与验证清单、来源日期、边界提示，移动端操作入口固定且不挡正文。
4. 业务工作台：私有草稿、状态面板、待处理列表、审核历史；不得在不安全的客户端声称已提交。
5. CMS 后台：审稿队列、版本差异、素材权属、受控发布/撤回；与个人档案、企业资料隔权。

基础组件名：SiteHeader、MainNavigation、HeroBanner、ContentCard、EvidenceBadge、FilterBar、EmptyState、Skeleton、MediaGallery、DraftForm、StatusTimeline、ModerationPanel、ToastFeedback、RightsLabel。组件以数据合同驱动，不允许单页自带另一套独立导航。

## 3. 动效与可访问性

- 动效只服务信息层级：入场 180–320ms，悬停 150–250ms；不能阻碍点击或覆盖重要信息。
- prefers-reduced-motion 必须生效，图片和滤镜在低端移动设备降级，避免自动播放音频/视频。
- 组件必须支持键盘焦点、Esc 关闭非模态菜单、语义按钮、关联标签、加载/空/错误状态。
- 测试断点：360 / 390 / 768 / 1024 / 1440px；至少 Chromium 桌面和移动模拟，发布前复核真机 Safari 或明确未验证。
- 大图必须标识真实作品或“AI 概念图”，不能让 AI 生成图冒充客户项目。
- 最低技术目标：LCP≤2.5s、INP≤200ms、CLS≤0.1，实际数值只允许采集后报告，不得写成既有成绩。

## 4. G1 前端验收

- 公开首页和目录、详情、工作台均有统一页面头部、字体层次、图标语义、按钮状态。
- 交互完整：搜索空值、长字段、内容加载失败、权限拒绝、表单重置、移动菜单无触发死角。
- F2.1 令牌与旧页 CSS 进行差异对比；发布 PR 后不得重新出现旧 ring/灯箱/重复推荐区。
- 涉及 UX 改动必须附 1440px / 390px 截图或自动化浏览器证明与 Cloudflare 真实路径验收。
