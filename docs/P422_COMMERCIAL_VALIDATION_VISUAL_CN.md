# P4.22｜商业证据可视化：从类别证据进入具体项目

核查日期：2026-10-09。生产数据库证据读回与代码审核完成；本站新增功能尚须单独 CI/部署验收。

## 产品问题
当前首页只有“海外项目库 / 商业模式 / 收费方式”，用户误以为已采集行业盈利数据后可以证明这些具名公司盈利。事实不成立。应将**方向证据**和**具名项目的第一方产品存在证据**显著隔离。

## 本版对用户明确展示的内容
1. 首页首屏下新增「商业证据研究」入口，排在研究库之前，菜单与主视觉也可以访问。
2. 全新 `/validation/` 公开证据页，说明研究门槛并对六类方向显示三种证据：技术供给、商业挂牌、独立需求。
3. 结果区显示“达到证据门槛”和“尚未满足门槛”的区分，但绝不使用“验证盈利”“保证可复制”等措辞。
4. 每个方向只显示已通过权限审查的**类别聚合计数**。不公开供应商、原始挂牌标识、逐条商业金额、内部平台枚举或关联公司的推断。
5. 清楚标注数据更新模式：优先用现有公开 Edge Function 的 `view=catalog`（一项授权的公开聚合视图）进行前端只读更新；失败或非法响应，展示 **2026-10-09 08:45（北京时间）** 的历史汇总快照，并明确“非实时”。
6. 界面中的六类中文标题来自内置冻结白名单，不采用外部自由文本来生成 HTML；数值只接受安全非负整数，类别固定六种，缺失或结构异常时 fail-closed。

## 生产 SQL 只读取证（2026-10-09）
- 36 次 pipeline 记录状态成功（含 13 次商业市场、13 次 GitHub、9 次 npm、1 次初始化）。
- 商业市场挂牌 222、GitHub 仓库 389、相关机会证据 501（337 技术 / 164 商业）。
- 最近 6 类方向快照中：4 类符合 `public_ready`，2 类未通过。六类对应可计入需求证据均为 0。
- 最近快照时间北京时间 10 月 9 日 08:45–08:48。
- 这些证据记录属于**行业方向相关样本的关联**，不是审计销量／盈利；第三方挂牌披露绝不代表最终成交价。
- 本页历史汇总按 `public_opportunity_catalog_v01` 同期一致口径冻结。即使 API 不通仍能阅读基本解释，但不可写“正在实时采集成功”。

## 工程约束与发布
- 首页依旧是单 HTML / 单 CSS / 单 JS，8 张 3D WebP、双主题和导航不变；发布后 homepage 控制在 <260000 bytes。
- 验证页独立页面，不继续无限增加首页单文件体积，且不从仓库拷贝任何私有目录。
- `web/dist/validation/index.html` 仅由 `scripts/release/p412_build_public.py` 的公共白名单构建写入，站点 sitemap 包含该页；加入既有敏感来源扫描。
- 不部署/修改 Supabase Edge Function、数据库、Cron、Auth、RLS；仅 GET 现有公开聚合接口。
- 不变更 Cloudflare Workers、Pages 构建配置和套餐，不使用 TinyFish 付费浏览器。
- 遗留 PR #52 保持原样；静态 HTML 必须保留全部现有源保护与页面交互。

## 已知风险与未来工作
- 当 CDN 的运行环境禁止连接公开 Edge API，页面只能展示有明确时间标记的旧快照；不能虚称 LIVE。
- 浏览器对外公开的 Edge Function URL 不是内部原始数据源 URL，不能往公开响应添加原始商业市场平台明细。应后续评估静态公有聚合 JSON/CDN 缓存以控制 API 成本。
- 此阶段没有对某个具名项目进行一对一销量、真实收入或团队规模验证，也没有建立获客成本及独立客户需求证据。
- 未执行的真机 Safari 或 CDN 浏览器动态操作应标记 UNVERIFIED，而非假设通过。
- 后续还应按授权、数据质量和可解释性扩充多个独立商业数据来源，避免单一交易市场造成研究偏差。
